SeaQuake Alarm – An Early Warning for Coastal Safety

## 📌 Project Overview
SeaQuake Alarm is an Embedded Systems project developed as part of an internship through APSSDC. The project focuses on providing an early warning system for coastal areas by detecting possible earthquake/seaquake activity and generating an alarm to alert people.

The main objective is to improve disaster preparedness and provide timely warnings to reduce the risk to people living in coastal regions.

## ⚙️ Working Principle
The system continuously monitors the required parameters using sensing components. When the detected values cross a predefined threshold, the system identifies the possibility of abnormal activity and activates an alarm.

### Basic Flow
Sensor → Microcontroller → Signal Processing → Threshold Detection → Alarm/Warning
